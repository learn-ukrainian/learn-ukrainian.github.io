# TASK zno-markup-recovery-system

## Problem
ZNO/НМТ items that require letter underlines/highlights were emitted as plain text → unsolvable (ruined). #6657 quarantines them fail-closed. #6664 recovers 6 Підкреслені tasks. We need a **repeatable system**, not one-off JSON edits.

## Outcome
A maintainable pipeline that:

1. **Detects** markup-dependent tasks (existing `markup_integrity.py` — reuse).
2. **Recovers** marks from authoritative sources when possible:
   - Primary: scrape `zno.osvita.ua/ukrainian/{test_id}/` HTML for `<u>` / `<u><b>` around option letters (proven for zno:203 etc.).
   - Match recovered option lists to `zno_tasks.options_json` → `zno:{id}`.
   - Write/merge into `data/practice/zno-markup-overlay.json`.
3. **Rebuilds** decks: `python scripts/practice_deck/zno.py` (apply overlay + quarantine residual).
4. **Reports** residual still missing marks (IDs + stem class) to stdout + optional `batch_state/practice/zno-markup-recovery-report.json` (gitignored path ok).
5. **Tests** fixture-based (no network in CI): sample HTML snippet → optionMarks ranges; matching to options; merge overlay idempotent.
