# Word cards C0 — worked examples (#8978 AC-02, AC-03)

Ten card instances live in [`examples/`](examples/) as JSON validated against [`schemas/word-card-v1.schema.json`](../../../schemas/word-card-v1.schema.json). They are generated by [`examples/build_examples.py`](examples/build_examples.py) (so every id follows the formula in `schema.md` §4) and checked by `tests/validate/test_word_card_examples.py` (24 tests: schema validity, id reproducibility, byte-identical regeneration, the states below, and the source-removal recomputation). Every Ukrainian value is quoted from the databases (queries in `schema.md` §17 and `identity.md` §12); card ids are opaque example ids.

Run:
```bash
/home/ops/learn-ukrainian/.venv/bin/python docs/atlas/word-cards/examples/build_examples.py
/home/ops/learn-ukrainian/.venv/bin/python -m pytest tests/validate/test_word_card_examples.py -q
```

### 4a. Sources disagree on identity: `броня` — [`bronia-armour.json`](examples/bronia-armour.json), [`bronia-reservation.json`](examples/bronia-reservation.json)
- VESUM: one entry 30497, comment `xv2 броня́; бро́ня`. ULIF: homonym 1 `бро́ня` `(закріплення; документ про закріплення)`; homonym 2 header empty, paradigm `броня́`. kaikki (Atlas): `броня́`. Wiktionary row 11318 lists armour senses and `закріплення когось або чогось за ким-, чим-небудь; документ на це закріплення` under one spelling.
- At spelling level the stress field would be **conflict** (`броня́` vs `бро́ня`). Under the identity contract (`identity.md` §5 F) there are two cards at `medium`: armour `wc_v5r2b9nx3cfk` with `stress` **verified** (ULIF paradigm + kaikki, groups `G-ULIF`, `G-WIKI`), reservation `wc_w8g1k4qt7zhm` with `stress` **single-source** (ULIF headword). ## 7. What the examples deliberately show as thin or missing
- No СУМ-20 for any example word (the crawl holds 100 articles); `definition_uk` therefore comes from ВТС or ULIF text only, at single-source.
- `atlas0` sources without a snapshot date (kaikki, ВТС, Караванський) are cited with `atlas0@manifest-0.1/2026-09-11` and `extraction_version = atlas0-migration`; C1 re-extracts them.
- English glosses are scaffold fields (`level_policy`), single-source or unverified everywhere.
- No model-written Ukrainian: every value has a database locator; the aspect-pair evidence is quoted from the ВТС card as stored, spacing included.
