# Word cards C0 — worked examples (#8978 AC-02, AC-03)

Eleven card instances live in [`examples/`](examples/) as JSON validated against [`schemas/word-card-v1.schema.json`](../../../schemas/word-card-v1.schema.json), plus four companion instances in [`examples/companion/`](examples/companion/) (identity registry, overlay batch, suppression selectors, derivation records) validated against their companion schemas. They are generated by [`examples/build_examples.py`](examples/build_examples.py) (so every id follows the formula in `schema.md` §4) and checked by `tests/validate/test_word_card_examples.py` (63 tests: schema validity, id reproducibility, byte-identical regeneration, the states below, the source-removal recomputation, the resolver cases the design reviews reproduced — `schema.md` §8.3 — and the round-3 contracts in §6b–§6d). Every Ukrainian value is quoted from the databases (queries in `schema.md` §17 and `identity.md` §11); the language lane verified every value against `sources.db`/`vesum.db`/`atlas.db` (Gemini, 2026-09-28: zero model-generated Ukrainian, source anomalies faithfully preserved); card ids are opaque example ids.

**What changed in r2:** eligibility is `false` on every example mode and says why (ambiguous spelling-level evidence never satisfies a rule; `medium` identity never feeds meaning practice); the Караванський row is held `unsplit`; links are canonical records with evidence; the idiom's `extraction_confidence_min` is `low`; a twelfth id (`wc_0a1b2c3d4e5f`, the legacy `замок` article) shows the `split` state.

**What changed in r3:** the identity registry is a frozen input the generator reads (assembly raises `MissingAllocation` for an unallocated id) and it now allocates persistent source-record ids (`sr_`) with aliases; every build input in the manifest carries a content hash, including the `frazeolohichnyi` and Wiktionary tables and the curated-heteronyms file; every `values[]` entry carries its own evidence and paradigm resolutions expose `propositions{}` per slot; `card_version` covers the whole public card; the броня (armour) card gains a GRAC `frequency` assertion so the CEFR estimate can name its producing derivation; the companion derivations are an estimator record, a page record and an exercise **draft** (nothing all-zero); the suppression selectors key on `sr_` ids, pin a normaliser version and show a complete `fallback`.

## 6c. Registry, allocation and the manifest (`examples/companion/identity-registry.json`)

The registry (version 2) is a constant the generator **reads**; `card()` raises `MissingAllocation` for any card or sense id outside it (`test_assembly_refuses_ids_the_frozen_registry_does_not_allocate`). It allocates 12 card ids (11 cards + `wc_m3y6w9dc2sxr`, ULIF homonym 2 of `ключ`, which has no example file) and 23 source-record ids: 11 ULIF rows (aliases `register_position`, `content`, `query_headword_label`), 8 VESUM entries (`vesum_entry_form`), 2 PULS rows, the `frazeolohichnyi` row 568 and the Wiktionary row 11318 (`table_row`). The two `ключ` records (`ulif:entry:3`, `ulif:entry:98008`) carry the same weak alias with a note; `test_legacy_record_key_collides_and_correspondence_holds_ambiguous` re-identifies record 3 in a renumbered snapshot: through the weak alias alone → `ambiguous` hold and both rows suppressed; through `register_position` → `unique`. Every card's `build.inputs` names the registry (`d19b02ad…`), the overlay (`6058ca79…`), the selectors (`1b555453…`), ULIF, PULS, `frazeolohichnyi`, Wiktionary, atlas0 and the curated-heteronyms file by content hash; `test_build_manifest_hashes_every_input_and_covers_every_used_source` re-hashes the companion files and maps every assertion's source to a manifest entry.

## 6d. Versions

`card_version` is the sha256 of the whole public card minus `build`; `test_card_version_covers_identity_and_admission_state` shows that changing `identity.confidence`, an eligibility verdict or the review status changes it and that changing `build_id` does not. `test_public_projection_of_an_untouched_card_is_the_card` shows that recomputation is deterministic (the projection of a card with nothing suppressed is the card, version included).

## 7. What the examples deliberately show as thin or missing
- No СУМ-20 for any example word (the crawl holds 100 articles); `definition_uk` therefore comes from ВТС or ULIF text only, at single-source.
- Every example mode is ineligible. That is the contract working, not a defect: the examples are the hard cases, and the route to eligibility is documented per card (an overlay mapping the PULS row; a language-lane `identity` entry).
- `atlas0` sources without a snapshot date (kaikki, ВТС, Караванський) are cited with `atlas0@manifest-0.1/2026-09-11` and `extraction_version = atlas0-migration`; C1 re-extracts them.
- English glosses are scaffold fields (`level_policy`), single-source or unverified everywhere.
- No model-written Ukrainian: every value has a database locator; the aspect-pair evidence is quoted from the ВТС card as stored, spacing included.
