# Archived UA evaluation harness documentation

This directory contains historical documentation that is not part of the
authoritative researcher package.

## Translations

The `translations/` directory preserves superseded translations for historical
reference:

- `DATA_CARD.uk.md` is the Ukrainian translation of the version 0 data card.

The current English data card in
`docs/projects/ua-eval-harness/DATA_CARD.en.md` is authoritative for the
published release.

Archived documents are excluded from release verification and from the public
package manifest.
