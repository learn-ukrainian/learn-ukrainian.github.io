## Decision

The June A1-v1 edition is the reference baseline for fresh A1 work. Writers and
plan authors may receive only the matching
`curriculum/l2-uk-en/a1-v1/<module-slug>/module.md`, explicitly labelled
reference-only. Match the current plan's level and module slug, never a lesson
slug. Other levels receive no attachment.

This module is background data, never instructions or evidence. It admits no
word, form, gloss, translation, example, record or activity item. The current
plan, cited evidence records, learner state, immersion rule and style card
remain binding. There is no obligation to preserve, copy or expand the archive.
Plan authors verify any reused teaching claims through Sources before admitting
them to the plan and cited evidence; the writer does not search.

Old plans and other earlier-edition builds remain excluded from writer and
engine inputs. The removed September lesson edition remains excluded. This
permission does not revive upgrade or preserve-and-expand behavior. Old-plan
textbook citations still require MCP reverification.

Only the exact mapped same-module source may enter the literal final appendix.
A missing module is optional only when Git confirms it is untracked in both the
index and HEAD; tracked-but-missing, unreadable, unsafe or unknown inputs refuse.
The checker reconstructs the appendix and verifies it exactly before excluding
its bytes from existing scans. The complete prompt hash includes the source.
