### 2. Port `.mcp/servers/sources/server.py` (primary)
**Preferred minimal path — low-level `Server` constructor handlers:**

Current (broken on 2.0):
```python
from mcp.server import Server
server = Server("sources")
@server.list_tools()
async def list_tools() -> list[Tool]: ...
@server.call_tool()
async def call_tool(name: str, arguments: dict) -> list[TextContent]: ...
```

Target shape (match installed 2.0.0 signatures):
```python
from mcp.server import Server
from mcp.types import TextContent, Tool, ListToolsResult, CallToolResult, CallToolRequestParams
# handlers:
async def list_tools(ctx, params) -> ListToolsResult:
    return ListToolsResult(tools=[...])  # same Tool(...) entries as today

async def call_tool(ctx, params: CallToolRequestParams) -> CallToolResult:
    name = params.name
    arguments = params.arguments or {}
    # reuse existing handler dispatch; wrap list[TextContent] as CallToolResult(content=...)

server = Server("sources", on_list_tools=list_tools, on_call_tool=call_tool)
```

**Also required transport fixes:**
- `server.run(...)` in 2.0 is `(read_stream, write_stream, initialization_options, raise_exceptions=False)` — **drop `stateless=True`** from both SSE and StreamableHTTP paths (tests currently assert stateless; update them to match 2.0 reality, document in PR).
- Keep `/health`, `/sse`, `/mcp`, `/messages/` routes.
- Preserve the in-file note: do **not** reintroduce `http_transport.terminate()` after the ASGI response is finalized.
- Keep module-level `list_tools` / `call_tool` **callable for unit tests** if tests still import them; either keep thin wrappers named `list_tools`/`call_tool` that tests can call, or update tests to invoke via the registered handlers / `ListToolsResult.tools`. Prefer updating tests cleanly rather than hacks.

**Tool field:** pydantic model uses `input_schema`; JSON alias is still `inputSchema`. Existing tests use `.inputSchema` — verify against 2.0 Tool objects.
