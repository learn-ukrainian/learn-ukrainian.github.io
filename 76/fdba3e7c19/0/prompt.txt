`delegate.py dispatch --branch <lane-branch>` fails at worktree prep when an EARLIER dispatch worktree still holds the

launcher exits with only a launcher-log line — no task record — so settle-loops watching the task file see nothing.

## Outcome (two halves, both required)
1. At `--branch` attach time, a branch-holder dispatch worktree whose bound task is in a TERMINAL status, whose tree

   stale-holder release path uses — extend that mechanism, do not build a parallel one) and the attach proceeds.

   so a settle-loop watching `batch_state/tasks/<id>.json` fires instead of hanging on a file that never appears.
