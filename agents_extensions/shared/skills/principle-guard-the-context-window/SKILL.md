# Guard the context window

Context overflow drops reasoning quality. Size the phase, cap the files in play, and keep the main thread on the decision.

- Search first. Read the matching lines, not entire generated trees.
- Summarize a long log by the failing command, the error text, and the path. Leave the raw log where the command wrote it.
- Do not paste secrets, credentials, or private transcripts into the thread.
- A worker does not fan work out to delegates to save its own context. The driver dispatches with disjoint owned paths when the brief allows it (`swarm`).

The human analog is `principle-minimize-reader-load`.
