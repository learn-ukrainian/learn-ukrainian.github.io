# Swarm

Coverage across different slices, not several implementations of the same change. An N-implementation arena is out of policy and is not this skill.

Only the accountable driver fans work out, through the existing dispatch path, with disjoint owned paths, one complete brief per worker, and the research classification `workflow.md` requires. A worker does not sub-delegate.

1. Frame the question, the denominator, and the per-slice acceptance check.
2. Partition so no two workers write the same files.
3. Aggregate the reports. Disagreement or a missing slice stays unknown. Do not average it away.
4. The driver reviews, lands, and closes. Fan-out is not the cross-family review of record.

Do not use this to race models on one task or to pick a winner by vote.
