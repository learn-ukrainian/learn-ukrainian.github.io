# Automate me

Use this when the same correction has already happened more than once and should become a skill or a structural check. Do not mine unrelated or private history.

1. Look for an existing skill or rule that already says it. Extend that home. Do not paste a second copy.
2. Cluster only repeated, consistent agreements: response shape, verification, owned paths, review. One contradicted preference is noise.
3. Draft the smallest section that states the agreement, with one failure example. Reference other skills by path.
4. If the draft is new process, policy, or an agent-rule change, stop for designated approval. Edit `agents_extensions/` only. The driver deploys. A worker does not merge the draft.

Do not encode a one-off. Do not restate `drive-epic` or `local-code-review` inside the new text.
