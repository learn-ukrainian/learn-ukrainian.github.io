# Sharpen

Before starting, name how a careful practitioner would check the result from outside the change, what the user is actually after, and which constraints do not serve that goal. Loosen a constraint that does not serve the goal as readily as you add one that does. Leave choices that belong to the operator open.

Fold in only what makes the work better, not bigger. Keep one outside check that the result is right (`principle-prove-it-works`). Then do the work. Do not hand back a rewritten prompt instead of the work.
