1. Read the current handoff and `git status` / `git log` for this branch (`../../recall/SKILL.md`). Continuation across a context limit uses `../../thread-rollover/SKILL.md`.
2. Diff what landed against what the brief still requires. Do not redo a finished check.
3. Route the remainder to one playbook.
4. Re-verify any inherited claim you will rely on (`../../principle-prove-it-works/SKILL.md`). A prior self-report is not proof.
