## Purpose
Curates authentic Ukrainian idioms and phraseologisms sourced directly from:
1. Complete ULIF phraseological dictionary walks (`data/sources.db`).
2. Uzhhorod / Lviv / Kyiv academic phraseological corpora.
3. Natural idiom instruction dialogues teaching nuanced figurative usage and rejecting word-for-word calques from other languages.
